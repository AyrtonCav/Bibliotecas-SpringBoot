# Biblioteca

Aplicação de gerenciamento de biblioteca desenvolvida com Spring Boot e Spring Data JPA.

## Tecnologias

- Java 21
- Spring Boot
- Spring Data JPA
- H2 e PostgreSQL
- Maven

## Como executar

Execute os testes com:

```bash
./mvnw test
```

Para iniciar a aplicação:

```bash
./mvnw spring-boot:run
```
